# Golden Brew

A Persian (RTL) coffee-shop landing page built with **HTML, Tailwind CSS, and vanilla JavaScript** — no frameworks, no backend. Designed from Figma mockups kept locally in `figma/` (git-ignored, never pushed).

## Features

- Sticky glass header with shop mega-dropdown, cart dropdown, and dark-mode toggle
- Hero section with overlapping content card
- Latest products and best-sellers grids (discount / out-of-stock states)
- Promo banners, category circles, coffee-club banner, blog cards
- About + services, full footer with contact and quick links
- Mobile navigation sidebar and mobile cart sidebar
- Dark mode (class strategy, persisted in `localStorage`) and responsive layouts

## Tech Stack

- HTML5 + Tailwind CSS v4.3 (CLI build) + vanilla JS
- Persian fonts: Dana and Morabba (local `woff2`)

## Getting Started

Requirements: Node.js 18+.

```bash
npm install
npm run dev      # rebuilds public/styles/style.css on every change (keep running)
```

Serve the folder with any static server, e.g.:

```bash
npx serve .
```

Then open the printed `http://localhost:3000` address.

## Scripts

| Script        | What it does                                              |
| ------------- | --------------------------------------------------------- |
| `npm run dev` | Tailwind watch build: `src/main.css` → `public/styles/style.css` |
| `npm run build` | One-off minified production build to the same output file |

Tailwind entry: `src/main.css` (imports `fonts.css` and `input.css`, defines theme tokens).

## Project Structure

```
index.html               # the whole page
src/                     # tailwind entry + fonts + hero background rule
public/
  styles/style.css       # generated by the Tailwind CLI (committed)
  scripts/app.js         # theme toggle + sidebar open/close
  images/                # products, blogs, categories, club, shapes
  fonts/                 # Dana + Morabba woff2
figma/                   # local-only design reference (ignored by git)
```

## Deployment

Fully static — deploy `index.html` together with `public/` on any static host (e.g. GitHub Pages). No build step is required on the server if the committed `public/styles/style.css` is up to date.

## Accessibility & Quality Notes

- Semantic landmarks, skip link, labeled icon buttons, `aria-expanded` on the mobile menu, Escape-to-close sidebars, visible `:focus-visible` ring, `prefers-reduced-motion` support.
- Known limitation (kept intentionally to preserve the Figma design): some brand-orange text on white is below WCAG AA contrast — revising the palette needs a designer decision.
